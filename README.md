# Goals

As metas de vocês dois, com quadradinhos de depósito.

## Como usar

- Cada um entra com o próprio e-mail e senha. Os dois veem as mesmas metas, atualizadas na hora.
- Em “Nova meta”, escolham o valor, o prazo e a frequência dos depósitos. O app monta os quadradinhos para somar exatamente o valor.
- Toquem no quadradinho depois de depositar. Sem internet, a marcação fica guardada no celular e sobe quando a conexão voltar.
- No botão de ajustes, no canto de cima: editar o nome que aparece para o outro, escolher o tema e a ordem das metas, baixar ou restaurar uma cópia, exportar os depósitos em planilha, trocar a senha e sair da conta.
- Dá para instalar como aplicativo. No Android, pelo Chrome: “Instalar app” ou “Adicionar à tela inicial”. No iPhone, pelo Safari: Compartilhar e depois “Adicionar à Tela de Início”.

As metas ficam no Firebase (projeto desafio-2027), protegidas pelo login e pelas regras do Firestore. Nada é salvo no GitHub.
